# 食材准备栏完整主体抠图方案

## 目标

保留当前菜谱详情页三栏结构、字体、卡片尺寸与文字排版，只替换食材准备栏的图片表现。所有图片必须完整显示主体，不裁切盘子、碗、肉类边缘或纵向散落构图。

## 素材与映射

主食材直接复用菜谱已有的 `primaryCategory`，不新增分类体系：

- `chicken`：鸡肉透明主体素材；
- `pork`：猪肉透明主体素材；
- `beef`：牛肉透明主体素材；
- `lamb`：羊肉透明主体素材；
- `fish`：鱼肉透明主体素材；
- 其他分类继续使用现有安全回退，不错误借用另一种肉类。

新增主食材素材采用透明 PNG，主体居中、边缘完整，四周保留安全区，不带方形背景、桌面、边框或文字。

配料统一使用辣椒、花椒、葱段从上到下自然排列的纵向散落透明素材。调味料统一使用深色酱汁、浅色油料、粉料与透明液体小碟从上到下排列的透明素材。两者属于装饰性通用素材，不声称逐项对应每道菜的全部内容。

## 页面呈现

- 三张卡继续横向并列，不改变文字和菜谱数据。
- 图片使用独立装饰层和 `object-fit: contain`，不得使用会裁切主体的 `cover`。
- 主体图允许轻微进入文字区域，但不得明显遮挡食材名称或用量。
- 配料与调味料保持纵向中轴构图，形成自然分隔感。
- 320px 与 393px 宽度下完整显示主体，无横向滚动。
- 图片加载失败时保留现有中性回退，页面不得报错。

## 数据流

菜谱解析和保存流程继续产出既有 `primaryCategory`。详情页只读取该字段选择主食材本地素材；配料组和调味料组分别选择固定通用素材。选择结果只影响视觉资源，不写入数据库、不改变分类来源。

## 修改范围

只新增菜谱详情页视觉映射、透明素材及食材卡图片呈现规则。禁止修改风味地图、Chicken Station、分类算法、Supabase、路由、菜谱正文、步骤和其他页面。

## 验收

- 辣椒炒肉显示完整猪肉主体，不再显示被截断的横向照片。
- 鸡、猪、牛、羊、鱼稳定得到对应主食材素材。
- 配料与调味料稳定使用批准的纵向通用构图。
- 图片无裁边、无方形照片底、无明显文字遮挡。
- 相关测试、lint 与 build 通过。
- 320px 和 393px 浏览器验收通过。

## 回退

本轮实现位于隔离分支 `codex/ingredient-balance`。如果视觉不符合预期，移除本设计之后的素材、映射和样式改动，即可返回基线提交 `f1e1c68`。
