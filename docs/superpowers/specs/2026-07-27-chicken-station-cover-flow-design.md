# Chicken Station Cover Flow 交互设计

## 目标

只重构 Chicken Station 的卡片交互，使卡片在拖动、惯性滑行和吸附过程中呈现连续的三维空间关系。现有菜谱数据、路由、卡片内容、页面文案和其他页面保持不变。

## 交互模型

卡片位置由一个连续的“卡片进度”驱动，而不是只在整数索引之间切换。用户拖动时，水平位移实时换算为进度；每张卡根据自己与当前视觉中心的连续距离，插值计算位置和外观。

- 轻微慢拖且未超过阈值：回弹到当前卡。
- 慢拖超过阈值：最多移动一张卡。
- 中速甩动：根据投影距离移动一至两张卡。
- 高速甩动：根据投影距离移动两至三张卡。
- 实际移动数量受现有卡片数量限制，不产生无意义的多圈循环。
- 多卡甩动时，每张经过的卡都连续穿过中心，不直接跳转索引。

## 三维视觉

卡片舞台提供统一的 perspective。每张卡根据与中心的距离连续计算：

- `translateX`：形成横向展开；
- `translateY`：侧卡稍微下沉；
- `translateZ`：侧卡向空间后方收纳；
- `rotateY`：左右卡分别向中心内收；
- `scale`：中心卡保持 1，侧卡逐级缩小；
- `opacity`、`brightness`、轻量 `blur`：强化景深；
- `box-shadow`：中心卡阴影最清晰，侧卡阴影逐级减弱；
- `z-index`：根据连续距离确定层级。

中心卡的目标状态为 `scale: 1`、`opacity: 1`、`blur: 0`、`rotateY: 0`，并拥有最高层级。

## 释放、惯性与吸附

释放时同时读取拖动距离和水平速度，先估算短距离惯性投影，再决定目标卡数。最终动画使用带阻尼的弹簧完成吸附，时长感受控制在约 250–450ms。

动画结束后再提交新的活动索引，并把连续位移无缝归零。归零前后的视觉位置等价，因此不会出现跳帧。

## 性能策略

- 只动画 `transform`、`opacity` 和轻量滤镜；
- 使用 MotionValue 派生每张卡的状态，拖动期间不触发 React 高频重渲染；
- 使用 `translate3d`/三维 transform、`will-change` 和 `backface-visibility`；
- 模糊半径保持很小，避免移动端 GPU 过载；
- 支持 `prefers-reduced-motion`，减少位移和弹簧运动。

## 可访问性

- 中央卡保留明确的可点击入口；
- 左右卡与页码点仍可直接选择；
- 拖动区域使用 `touch-action: pan-y`，不阻断页面纵向滚动；
- 减少动态效果的系统偏好会得到更短、更克制的过渡。

## 不变边界

本次不修改菜谱数据、分类逻辑、Supabase、API、路由、数据接口、Flavor Map、首页、加载页、菜谱详情页，以及 Chicken Station 卡片内容、文案和数据结构。

## 验证

- 为连续插值、三维层级、速度分级、卡片数限制编写纯函数测试；
- 运行现有测试、lint 和 production build；
- 在约 390px 宽移动端视口验证慢拖、快速甩动、回弹、侧卡点击、中心卡进入详情，以及页面无横向溢出。
