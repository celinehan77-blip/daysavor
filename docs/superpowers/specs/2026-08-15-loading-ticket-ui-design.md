# 收藏票根生成页 UI 精修设计

## 范围

本阶段只精修现有 `/loading` 页面，不修改后台任务、数据库、API、生成状态持久化、路由或菜谱保存流程。

## 视觉结构

- 保留“正在制作收藏票根”和现有副标题。
- 中间使用现有四张票根，不创建重复页面；四张票根统一宽高、圆角和纸张材质，但内容随生成阶段逐步简化。
- 从上到下严格使用递减 `z-index`，四张票根保持完整的 2:1 比例，每张仅向上重叠约 12～18px，并通过轻微错位和旋转表现真实纸张叠放。
- 四张卡片采用固定而非随机的轻微水平错位与 ±1.5° 内旋转。
- 第一张显示完整“你的菜谱 / Your Recipe / FROM / TO”；后三张依次显示“食材识别完成 / 步骤整理完成 / 票根制作完成”。
- 四张卡片分别使用绿色叶片、绿色叶片、暖金锅具和陶土星形印章，印章作为低对比度纸面印刷。
- 中文主标题使用思源宋体优先的衬线字体栈，辅助文字使用苹方体系；英文标题与票据小字分开使用经典衬线和系统无衬线字体。
- 卡片下方保留五步进度，完成项为绿色勾选，当前项为暖金呼吸圆环。
- 页面底部增加轻量 AI 提示卡，只显示“AI 生成中 · 大约需要 10–20 秒”，不出现退出页面、后台继续生成或稍后查看等第二行提示。

## 动效

- 四张票根按下层到上层错峰出现，间隔约 80ms。
- 只使用透明度、12px 位移和最终轻旋转，不增加循环漂浮、夸张弹簧或 3D。
- 支持 `prefers-reduced-motion`。

## 验收

- 320px、390px 无横向溢出。
- 四张卡片尺寸一致、层级正确、没有穿模。
- 标题、票根、进度和提示卡在移动端可纵向滚动完整查看。
- 现有生成与跳转逻辑保持不变。
